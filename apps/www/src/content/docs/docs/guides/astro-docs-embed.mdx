# Use URK inside Astro docs

Astro and Starlight own the documentation shell. URK owns live runtime islands inside that shell.

Markdown with JSX-style components (MDX) can host a component that mounts a runtime on the client.

```mdx
import LiveURKExample from '@/components/urk-runtime/LiveURKExample.astro';

<LiveURKExample example="embedded-docs-demo" />
```

Status: current. The runnable public proof is [Embedded Docs Demo](/examples/embedded-docs-demo/).

## Try the embedded widget

This island mounts the same widget as the standalone `/motion-widget/` proof.
Scrub its sequence, adjust playback speed or timing, and replay. The host's Pause
and Resume controls preserve motion position. Shutdown removes the widget while
this documentation stays readable; Reset / restart mounts it with a fresh kernel.
Reduced motion follows your system preference, and offscreen work suspends automatically.
Enable **Remember settings on this device** to restore committed timing and speed
after a reload or fresh runtime restart. Turn it off to forget saved settings;
current playback stays unchanged. Playback position and pause state are never saved.
Use **Share settings** to export the current timing/speed as JSON or import a preset
from another widget. Import preserves position and pauses; new timing starts on
the next replay. Invalid input leaves the current settings unchanged.

The shared implementation lives in `packages/examples/src/motion-widget/`.
Its `mountMotionWidget(host, ctx, options)` helper borrows a controller's runtime
context and scope. It creates no kernel and changes no experience phase. The
private `@urk/examples/motion-widget` subpath is a repository reuse point; copy
the example into an application rather than relying on it as a stable npm API.

## Rules

- docs content must render before the runtime island starts
- runtime island failures must stay local to the island
- `@urk/examples` remains private and unstable
