[Open Audio Lab](/examples/audio-proof/). This is the public adaptation of the original `examples/audio-proof/` integration proof.

## Try it

1. Choose Ambient bed, Pulse cue, or Confirmation to play a real WAV track. Sound never starts automatically.
2. Adjust Volume or Mute. Pause track holds its position; Stop rewinds it.
3. Pause the runtime using the controls below the deck. Audio pauses too. Resume the runtime, then press Play to continue listening.
4. Shutdown releases the audio adapter. Reset / restart creates a fresh kernel and deck state.
5. Inspect the runtime panels below for `audio:changed` and `audio-demo:*` events.

All controls are native buttons or a labeled slider and support keyboard interaction. The record animation indicates playback state; it is not a waveform or spectrum analyzer. Reduced-motion preferences disable the rotation.

## How URK is used

`packages/examples/src/audio-proof/mount.ts` creates a kernel with `createAudioAdapter()` from `@urk/adapters` and `createLoadingAdapter()` from `@urk/adapters/dom`. The controller registers three tracks, resolves the audio capability, and coordinates media state with runtime pause and disposal. Tracks load on demand when played; loading status and playback errors appear on the deck.

The Astro component owns the static HTML, styling, and track asset URLs. `view.ts` updates those elements from adapter snapshots. The existing runtime panel helper handles diagnostics and reset/teardown wiring.
