# Playground starter

Status: experimental.

The playground is a runtime lab for exploring URK concepts. It is not a no-code builder and not a stable product API.

Open the [live Playground](/playground/). It runs the shared v0.2 experience directly: pick Explore, Create, or Connect, rotate with arrow keys, enable sound, and exercise pause, cleanup, and recovery. [Usage details](/docs/guides/urk-v02/) explain the controls and saved preferences. The `/v02/` route remains available.

The existing [config inspector](/playground/config/) validates known-example config, shows adapter/controller metadata, and links to individual examples.

## Intended lesson

- coordinate Three.js, pointer, keyboard, storage, audio, loading, and overlays
- render on interaction and rest while idle
- release resources when leaving the page and create a fresh kernel on return
- inspect known-example config separately

## Current boundary

- Config is limited to current public examples.
- Adapter and controller names must match selected example metadata.
- Custom JavaScript is rejected by design.
- Shared runtime orchestration stays in the private examples package; the website owns mounting and navigation cleanup.
